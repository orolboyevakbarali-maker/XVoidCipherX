# FunboxEasyEnum — OffSec Training Lab

## Overview
FunboxEasyEnum is an OffSec training lab focused on enumeration,
web application security, Linux privilege escalation, and system access.

## Learning Objectives
- Discover services and hidden directories using Nmap and Gobuster.
- Identify a web application file-upload vulnerability.
- Enumerate system users and investigate SSH access.
- Practice Linux privilege escalation in an authorized lab.
- Obtain root access and document the final result.

## Tools
- Kali Linux
- Nmap
- Gobuster
- Web browser
- SSH
- Linux command-line utilities

## Methodology

### 1. Reconnaissance
Identify the target IP address and scan available ports and services.

### 2. Web Enumeration
Enumerate web directories and inspect the web application for
potential vulnerabilities.

### 3. Initial Access
Investigate the file-upload functionality and validate findings
within the authorized lab environment.

### 4. SSH Access
Enumerate users and test any credentials discovered during the lab.

### 5. Privilege Escalation
Investigate permitted privilege escalation paths and document
the evidence for any elevated access.

### 6. Completion
Record the final result and add screenshots demonstrating
the completed steps.
