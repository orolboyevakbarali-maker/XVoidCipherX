# OverTheWire Bandit — Linux Command-Line Practice

## Overview

This repository contains my notes and practical learning materials from the OverTheWire Bandit wargame.

The project documents my progress in Linux command-line usage, file handling, permissions, and basic security concepts.

## Topics Covered

- Linux terminal commands
- SSH connections
- File and directory navigation
- Reading hidden files
- File permissions and ownership
- Finding files by name, size, and type
- Text processing
- Pipes and redirection
- Basic Linux security concepts

## Lab Environment

- Operating System: Kali Linux
- Connection: SSH
- Platform: OverTheWire Bandit

## Repository Contents

- `Bandit-Notes.md` — Notes exported from Notion.
- `BANDIT/` — Screenshots and images associated with the notes.

## Learning Objectives

- Improve Linux command-line skills.
- Understand common file-system operations.
- Practice beginner-level security challenges.
- Document practical learning progress.
